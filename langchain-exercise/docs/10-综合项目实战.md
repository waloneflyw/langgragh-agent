# 10 — 综合项目实战：企业智能客服助手

> 目标：用前面学到的全部知识，从零构建一个**可运行、可面试展示**的完整项目——
> 企业智能客服助手。它集成了 **RAG + 工具调用 + Agent + 记忆 + 结构化输出** 五大能力。

---

## 1. 项目需求

做一个"XX 电商公司"的智能客服，能：

| 能力 | 具体场景 | 用到的技术 |
|------|---------|-----------|
| **知识问答** | 问"退货政策是什么" | RAG（检索公司文档） |
| **订单查询** | 问"我的订单到哪了" | Tool（查订单工具） |
| **库存查询** | 问"iPhone15 有货吗" | Tool（查库存工具） |
| **算账** | 问"满减后多少钱" | Tool（价格计算） |
| **多轮记忆** | 先说"我订单号A123"，再问"它到哪了" | Memory |
| **结构化输出** | 生成"订单详情"对象 | Pydantic |

**一句话目标**：做一个"会查资料、会查数据、记得上下文"的客服 Agent。

## 2. 项目文件结构

```
langchain-exercise/
└── customer-service/
    ├── .env                 # API Key（不提交git）
    ├── requirements.txt     # 依赖清单
    ├── config.py            # 模型配置（统一入口）
    ├── tools.py             # 业务工具（订单/库存/算账）
    ├── knowledge.py         # RAG 知识库（公司制度文档）
    ├── agent.py             # 组装智能体（含记忆）
    └── main.py              # 命令行交互入口
```

**为什么这样拆**（面试加分：体现工程化思维）：
- `config.py` 统一管理模型，换厂商只改一处
- `tools.py` 工具和业务逻辑分离，可独立测试
- `knowledge.py` 知识库独立，方便替换数据源
- `agent.py` 组装层，业务代码不碰 LangChain 细节
- `main.py` 只管交互，和核心逻辑解耦

## 4. 第 2 步：业务工具（tools.py）

```python
from langchain_core.tools import tool

# 模拟数据库：订单和库存
ORDERS = {
    "A123": {"商品": "蓝牙耳机", "状态": "已发货，预计明天到达", "金额": 299},
    "B456": {"商品": "机械键盘", "状态": "待发货", "金额": 499},
}
STOCK = {"蓝牙耳机": 120, "机械键盘": 0, "充电宝": 500}

@tool
def query_order(order_id: str) -> str:
    """根据订单号查询订单状态和商品信息。订单号形如 A123。"""
    order = ORDERS.get(order_id)
    if not order:
        return f"未找到订单号 {order_id} 的订单，请核对后重试。"
    return f"订单 {order_id}：商品为{order['商品']}，状态为{order['状态']}，金额{order['金额']}元。"

@tool
def check_stock(product: str) -> str:
    """查询某商品的库存数量。"""
    count = STOCK.get(product)
    if count is None:
        return f"没有找到商品「{product}」的库存记录。"
    return f"商品「{product}」当前库存：{count}件" + ("，有货" if count > 0 else "，已售罄")

@tool
def calc_discount(amount: int, threshold: int, discount: int) -> int:
    """计算满减后应付金额：满 threshold 元减 discount 元。"""
    return amount - discount if amount >= threshold else amount
```

> 关键点：每个工具的 **docstring 都写清了"何时用、参数是什么"**，这是 Agent 正确调用的前提。

## 5. 第 3 步：知识库（knowledge.py）

把公司制度文档做成 RAG：

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import FAISS
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from config import get_embeddings, get_llm

# 公司制度文档（实际应从文件/数据库读取）
DOCS = """
退货政策：自签收之日起7天内可无理由退货，商品需保持完好。
物流说明：全国包邮，偏远地区加收20元运费，发货后3-5天送达。
售后政策：商品质量问题1年内免费保修，人为损坏不保修。
发票说明：支持开具电子发票，下单时可备注抬头。
"""

def build_retriever():
    splitter = RecursiveCharacterTextSplitter(chunk_size=80, chunk_overlap=15)
    chunks = splitter.split_text(DOCS)
    vectorstore = FAISS.from_texts(chunks, embedding=get_embeddings())
    return vectorstore.as_retriever(search_kwargs={"k": 3})

def ask_knowledge(question: str) -> str:
    """基于公司文档回答（纯 RAG，无工具）"""
    prompt = ChatPromptTemplate.from_messages([
        ("system", "你是公司客服，只根据以下资料回答，资料没有就说'抱歉，我暂不清楚，可转人工'。\n{context}"),
        ("human", "{question}"),
    ])
    chain = (
        {"context": build_retriever(), "question": lambda x: x}
        | prompt | get_llm() | StrOutputParser()
    )
    return chain.invoke(question)
```

## 6. 第 4 步：组装智能体（agent.py）

用 `create_react_agent` 把工具+知识结合，再加多轮记忆：

```python
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langgraph.prebuilt import create_react_agent
from langgraph.checkpoint.memory import MemorySaver
from config import get_llm
from tools import query_order, check_stock, calc_discount

# 定制人设：告诉 Agent 它的身份和行为规范
system_prompt = ChatPromptTemplate.from_messages([
    ("system", """你是「XX电商」的智能客服，名叫小悦。
    规则：
    1. 查询订单用 query_order，查库存用 check_stock，算满减用 calc_discount
    2. 涉及退货/物流/售后政策的知识，先用你的专业知识回答，不确定就引导查资料
    3. 回答简洁友好，用中文
    4. 记住用户之前说过的话（如订单号）"""),
    MessagesPlaceholder("messages"),
])

def build_agent():
    # MemorySaver 提供持久化记忆（生产可换数据库）
    memory = MemorySaver()
    agent = create_react_agent(
        model=get_llm(),
        tools=[query_order, check_stock, calc_discount],
        state_modifier=system_prompt,
        checkpointer=memory,
    )
    return agent
```

> `checkpointer=MemorySaver()` 让 Agent 具备**多轮记忆**能力（第 05 篇的机制 + 第 08 篇的持久化）。

## 7. 第 5 步：交互入口（main.py）

```python
from agent import build_agent

def main():
    agent = build_agent()
    print("小悦：你好！我是 XX 电商客服，请问有什么可以帮您？(输入 exit 退出)\n")

    # 用 thread_id 标识当前会话，实现多轮记忆
    thread_id = "customer-1"
    while True:
        user_input = input("你：")
        if user_input.lower() == "exit":
            break

        result = agent.invoke(
            {"messages": [("human", user_input)]},
            config={"configurable": {"thread_id": thread_id}},
        )
        print(f"小悦：{result['messages'][-1].content}\n")

if __name__ == "__main__":
    main()
```

## 9. 项目亮点总结（面试时怎么讲）

面试官问"做过什么智能体项目"，你可以这样讲这个项目：

1. **架构**：用 `create_react_agent` + 3 个业务工具 + RAG 知识库，做成一个客服 Agent
2. **多轮记忆**：用 `MemorySaver` + `thread_id` 实现用户会话隔离
3. **工程化**：配置/工具/知识库/组装/入口分层，换模型只改 `config.py` 一处
4. **可扩展**：知识库换成数据库、工具换成真实 API、记忆换成 Redis，架构不变

## 10. 项目升级方向（练手/面试谈资）

| 方向 | 做法 | 涉及知识 |
|------|------|---------|
| **接入真实数据** | 工具里的 mock 换成真实数据库/API 调用 | Tool + 外部系统 |
| **多用户隔离** | thread_id 换成真实用户 ID | Memory |
| **多智能体** | 把"售前/售后/物流"拆成三个 worker + supervisor | 第 09 篇 |
| **Web 服务** | 用 FastAPI 把 Agent 包装成 HTTP 接口 | 部署 |
| **流式前端** | Agent 用 `.stream` 输出，前端打字机展示 | stream |
| **人工兜底** | 知识库答不上时转人工 | LangGraph interrupt |

```python
# mini_demo.py —— 把整个项目压成一个文件，先跑通理解全貌
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langgraph.prebuilt import create_react_agent
from langgraph.checkpoint.memory import MemorySaver

load_dotenv()
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

@tool
def query_order(order_id: str) -> str:
    """根据订单号查询订单状态。订单号形如 A123。"""
    return {"A123": "蓝牙耳机，已发货，预计明天到达"}.get(order_id, "未找到该订单")

agent = create_react_agent(
    llm, tools=[query_order],
    state_modifier=ChatPromptTemplate.from_messages([
        ("system", "你是客服，记住用户说的订单号。"),
        MessagesPlaceholder("messages"),
    ]),
    checkpointer=MemorySaver(),
)

cfg = {"configurable": {"thread_id": "t1"}}
print(agent.invoke({"messages": [("human", "查订单A123")]}, config=cfg)["messages"][-1].content)
print(agent.invoke({"messages": [("human", "它什么时候到？")]}, config=cfg)["messages"][-1].content)
```
